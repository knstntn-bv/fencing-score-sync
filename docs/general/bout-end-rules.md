# Логика окончания боя

Источник правды для судьи — кнопки на табло, не автоматический конец по времени. Правила ниже — про клубное табло (вошедший аккаунт). В **Quick bout** кнопки Save нет, запись невозможна.

## Счёт

Пока таймер **идёт**, кнопки +/− неактивны.

Счёт можно менять:

- до первого Start;
- на паузе;
- после того как таймер дошёл до 0.

Состояние победы **не** блокирует кнопки счёта: можно поправить укол.

## Победа на табло

Как только один счётчик **первым** достигает лимита очков, включается победа этой стороны.

Это:

- блокирует **выход таймера из паузы** (Start нельзя);
- не блокирует +/−.

Если поправкой счёт победителя снова ниже лимита, победа сбрасывается. Если при этом у соперника уже лимит — победа переходит к нему.

Истечение времени само по себе победу не ставит.

## Сохранение

Кнопка сохранения на клубном табло **всегда на экране**. В Quick bout её нет.

| Состояние | Кнопка |
|---|---|
| Анонимный бой (оба без имён) | Заблокирована, подпись «Save result», меток нет |
| Таймер идёт | Заблокирована (для именного подпись/метки всё равно отражают текущий исход) |
| Пауза / до старта / время вышло, бой именной, равный счёт | «Save draw» |
| Пауза / до старта / время вышло, бой именной, счёт неравный | «Save victory» + синяя метка слева или красная справа у лидера |
| Уже сохранено | Заблокирована, «Saved» |

В запись кладутся клиентский `id`, `club_id`, id и снимки имён, счёт, лимиты, остаток таймера, `started_at` / `finished_at` и **результат каждого** (`blue_result` / `red_result`):

- больше очков → `win`, меньше → `lose`;
- равный счёт → обоим `draw`.

Как остановился бой (лимит очков или ноль на таймере) в таблицу не пишется: нет `ended_by`, нет `winner_id`. Кнопка Save смотрит на счёт, не на защёлку лимита: 7–3 при лимите 12 — «Save victory».

Анонимный бой в таблицу не пишется.

Если сети нет (или `fetch` падает), тот же payload уходит в outbox и кнопка становится «Saved». Повторная отправка с тем же `id`: Postgres `23505` считается успехом, дубль не создаётся.

## Reset

Пока таймер идёт — заблокирован. На паузе (и до старта / после нуля) можно.

Срабатывает после **удержания 1 с** (мышь и touch). Обнуляет счёт, снимает победу, ставит таймер на полный лимит, **оставляет выбранных бойцов**.

## Схема

Актуальное состояние Postgres: `supabase/final_schema.sql`.
Инкремент для уже существующего проекта: `supabase/migrations/`.

## Не делается

Автосохранение по нулю таймера, realtime-табло на втором экране.
